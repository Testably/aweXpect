These benchmarks compare aweXpect's happy-path overhead (passing assertions, the dominant case in a healthy test suite) against the equivalent [FluentAssertions](https://fluentassertions.com/) and [TUnit](https://tunit.dev/) calls.

:::note[Methodology]

- **Suite**: [`HappyCaseBenchmarks`](https://github.com/Testably/aweXpect/tree/main/Benchmarks/aweXpect.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. **Lower is better.**

:::

<TabItem value="Multiple" label="Several at once">

Verifies three properties of an album at once, so that all failures would be reported together.

<BenchmarkResult name="Multiple" />

```csharp title="aweXpect"
await Expect.ThatAll(
    That(_multipleSubject.Title).IsEqualTo("Abbey Road"),
    That(_multipleSubject.Artist.Name).IsEqualTo("The Beatles"),
    That(_multipleSubject.Genre).IsEqualTo(Genre.Rock));
```

```csharp no-compile title="FluentAssertions"
using (new AssertionScope())
{
    _multipleSubject.Title.Should().Be("Abbey Road");
    _multipleSubject.Artist.Name.Should().Be("The Beatles");
    _multipleSubject.Genre.Should().Be(Genre.Rock);
}
```

```csharp no-compile title="TUnit"
using (Assert.Multiple())
{
    await Assert.That(_multipleSubject.Title).IsEqualTo("Abbey Road");
    await Assert.That(_multipleSubject.Artist.Name).IsEqualTo("The Beatles");
    await Assert.That(_multipleSubject.Genre).IsEqualTo(Genre.Rock);
}
```

<TabItem value="EventTriggered" label="Events">

Verifies that an event was raised, including starting the recording and raising the event.
TUnit has no event recording to compare against, so it is not part of this benchmark.
FluentAssertions' `Monitor()` emits a handler for each event of the object at runtime, which is where most of its time goes.

<BenchmarkResult name="EventTriggered" />

```csharp title="aweXpect"
using aweXpect.Recording;

Player player = new();
IEventRecording<Player> recording = player.Record().Events();
player.Play();
await That(recording).Triggered(nameof(Player.Started));
```

```csharp no-compile title="FluentAssertions"
Player player = new();
using IMonitor<Player> monitor = player.Monitor();
player.Play();
monitor.Should().Raise(nameof(Player.Started));
```

[View source on GitHub →](https://github.com/Testably/aweXpect/blob/main/Benchmarks/aweXpect.Benchmarks/HappyCaseBenchmarks.EventTriggered.cs)

</TabItem>

## Extension packages

The extension packages compare their main features with FluentAssertions on their own benchmark pages:

- [aweXpect.Json](/aweXpect/extensions/aweXpect.Json/benchmarks)
