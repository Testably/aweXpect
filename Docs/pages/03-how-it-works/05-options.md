# Options

*Structure preview: this page will introduce the option vocabulary that is shared by many expectations, instead of
explaining it again on each type page.*

- `Because(...)`: the reason for an expectation.
- `IgnoringCase()`, `IgnoringLeadingWhiteSpace()`, ...: string comparison options.
- `Using(comparer)`: a custom equality comparer.
- `Within(tolerance)`: a tolerance for numbers and times.
- `InAnyOrder()`, `IgnoringDuplicates()`: collection comparison options.
- `Equivalent()`: compare by equivalency instead of equality.
