These benchmarks compare the happy-path overhead of aweXpect.Json (passing assertions, the dominant case in a healthy test suite) against the equivalent [FluentAssertions](https://fluentassertions.com/) calls.

:::note[Methodology]

- **Suite**: [`HappyCaseBenchmarks`](https://github.com/Testably/aweXpect/tree/main/Benchmarks/aweXpect.Json.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- FluentAssertions has expectations on `JsonNode`, but not on JSON strings or `JsonElement`. Where it lacks an expectation, its benchmark does what a FluentAssertions user writes instead, e.g. parse the string into a `JsonNode`.
- Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. **Lower is better.**

:::

<TabItem value="JsonString" label="JSON string" default>

Verifies that a JSON `string` matches an expected object.
FluentAssertions parses the string into a `JsonNode`.

<BenchmarkResult package="aweXpect.Json" name="JsonString" />

```csharp title="aweXpect"
await That(_jsonString).IsValidJsonMatching(new { title = "Let It Be", artist = "The Beatles", });
```

```csharp title="FluentAssertions"
JsonNode.Parse(_jsonString).Should().BeEquivalentTo(new { title = "Let It Be", artist = "The Beatles", });
```

<TabItem value="JsonEquality" label="JSON equality">

Verifies that a JSON `string` is equal to an expected JSON string with a different property order and formatting.
FluentAssertions cannot compare two `JsonNode`s with `BeEquivalentTo`, so it parses both strings and verifies the result of `JsonNode.DeepEquals`.

<BenchmarkResult package="aweXpect.Json" name="JsonEquality" />

```csharp title="aweXpect"
await That(_jsonString).IsEqualTo(_expectedJsonString).AsJson();
```

```csharp title="FluentAssertions"
JsonNode.DeepEquals(JsonNode.Parse(_jsonString), JsonNode.Parse(_expectedJsonString)).Should().BeTrue();
```

[View source on GitHub →](https://github.com/Testably/aweXpect/blob/main/Benchmarks/aweXpect.Json.Benchmarks/HappyCaseBenchmarks.JsonEquality.cs)

</TabItem>

<TabItem value="JsonStringExpectations" label="JSON string expectations">

Verifies that a JSON `string` is valid JSON whose title has the expected value.
FluentAssertions parses the string into a `JsonNode`.

<BenchmarkResult package="aweXpect.Json" name="JsonStringExpectations" />

```csharp title="aweXpect"

```

```csharp title="FluentAssertions"
JsonNode.Parse(_jsonString)!.Should().HaveProperty("title").Which.GetValue<string>().Should()
    .Be("Let It Be");
```

<TabItem value="JsonStringCollection" label="Collection of JSON strings">

Verifies that all 100 JSON strings of a collection are equal to an expected JSON string with a different property order and formatting.
FluentAssertions parses the expected string once and verifies the result of `JsonNode.DeepEquals` for every item.

<BenchmarkResult package="aweXpect.Json" name="JsonStringCollection" />

```csharp title="aweXpect"

```

```csharp title="FluentAssertions"
JsonNode? expected = JsonNode.Parse(_expectedJsonString);
_jsonStrings.Should()
    .AllSatisfy(jsonString => JsonNode.DeepEquals(JsonNode.Parse(jsonString), expected).Should().BeTrue());
```

<TabItem value="JsonProperty" label="Properties">

<TabItem value="JsonPropertyChain" label="Combined expectations">

Verifies several expectations on the same `JsonNode`, combined with `And`: it has three properties, has no property `album` and is an object.
FluentAssertions has no expectation that a node is an object, so it verifies that it is no array instead.

<BenchmarkResult package="aweXpect.Json" name="JsonPropertyChain" />

```csharp title="aweXpect"
await That(_jsonNode)
    .HasProperty("title").And
    .HasProperty("artist").And
    .HasProperty("durationSeconds").And
    .DoesNotHaveProperty("album").And
    .IsObject();
```

```csharp title="FluentAssertions"
_jsonNode.Should().HaveProperty("title");
_jsonNode.Should().HaveProperty("artist");
_jsonNode.Should().HaveProperty("durationSeconds");
_jsonNode.Should().NotHaveProperty("album");
_jsonNode.Should().NotBeAnArray();
```

[View source on GitHub →](https://github.com/Testably/aweXpect/blob/main/Benchmarks/aweXpect.Json.Benchmarks/HappyCaseBenchmarks.JsonPropertyChain.cs)

</TabItem>
