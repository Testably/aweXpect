These benchmarks compare the happy-path overhead of aweXpect.Xml (passing assertions, the dominant case in a healthy test suite) against the equivalent [FluentAssertions](https://fluentassertions.com/) calls.

:::note[Methodology]

- **Suite**: [`HappyCaseBenchmarks`](https://github.com/Testably/aweXpect/tree/main/Benchmarks/aweXpect.Xml.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- FluentAssertions has expectations on `XElement` and `XDocument`, but not on XML strings. Where it lacks an expectation, its benchmark does what a FluentAssertions user writes instead, e.g. parse the string into an `XDocument`.
- Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. **Lower is better.**

:::

<TabItem value="XmlString" label="XML string" default>

Verifies that an XML `string` is equivalent to the expected one, regardless of its formatting and the order of its attributes.
FluentAssertions parses both strings into an `XDocument`.

<BenchmarkResult package="aweXpect.Xml" name="XmlString" />

```csharp title="aweXpect"
await That(_xmlSubject).IsEqualTo(_xmlExpectation).AsXml();
```

```csharp title="FluentAssertions"
XDocument.Parse(_xmlSubject).Should().BeEquivalentTo(XDocument.Parse(_xmlExpectation));
```

<TabItem value="ElementOrder" label="Element order">

Verifies that an `XElement` with 10 child elements is equivalent to the expected XML with the child elements in reverse order.
FluentAssertions has no XML equivalency that ignores the element order, so it only approximates the expectation by comparing the `sku` attributes of the child elements in any order.

<BenchmarkResult package="aweXpect.Xml" name="ElementOrder" />

```csharp title="aweXpect"
await That(_order).MatchesExactly(_reversedOrder, o => o.IgnoringElementOrder());
```

```csharp title="FluentAssertions"
_order.Elements("item").Select(item => item.Attribute("sku")!.Value).Should()
    .BeEquivalentTo(XElement.Parse(_reversedOrder).Elements("item").Select(item => item.Attribute("sku")!.Value));
```

[View source on GitHub →](https://github.com/Testably/aweXpect/blob/main/Benchmarks/aweXpect.Xml.Benchmarks/HappyCaseBenchmarks.ElementOrder.cs)

</TabItem>
