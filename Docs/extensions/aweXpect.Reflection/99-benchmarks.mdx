These benchmarks compare the happy-path overhead of aweXpect.Reflection (passing assertions, the dominant case in a healthy test suite) against the equivalent [FluentAssertions](https://fluentassertions.com/) calls.

:::note[Methodology]

- **Suite**: [`HappyCaseBenchmarks`](https://github.com/Testably/aweXpect/tree/main/Benchmarks/aweXpect.Reflection.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- FluentAssertions has no expectations on nullability or dependencies. For these, its benchmark does what a FluentAssertions user writes instead, which does not cover everything aweXpect.Reflection verifies.
- Each tab shows the latest measured time and allocated memory; bars are scaled within the row so length corresponds to magnitude. **Lower is better.**

:::

<TabItem value="TypeNullability" label="Nullability">

Verifies that all members of a type are non-nullable.
FluentAssertions reads the nullability of the declared properties with a `NullabilityInfoContext` and verifies that none of them is nullable. As the type only has auto-properties, this covers the same members.

<BenchmarkResult package="aweXpect.Reflection" name="TypeNullability" />

```csharp title="aweXpect"
await That(_trackType).OnlyHasNonNullableMembers();
```

```csharp title="FluentAssertions"
NullabilityInfoContext context = new();
_trackType.GetProperties(DeclaredMembers).Select(property => context.Create(property).ReadState)
    .Should().NotContain(NullabilityState.Nullable);
```

<TabItem value="TypesDoNotDependOn" label="Dependencies">

Verifies the architecture rule that no type in a namespace of an assembly depends on the `System.Net` namespace.
FluentAssertions collects the types of the fields, properties, method return values and method parameters and verifies that none of them is in the namespace. This is not equivalent: it ignores e.g. base types, interfaces, generic arguments and attributes.

<BenchmarkResult package="aweXpect.Reflection" name="TypesDoNotDependOn" />

```csharp title="aweXpect"
await That(In.AssemblyContaining<HappyCaseBenchmarks>().Types().WhichAreWithinNamespace(_namespace))
    .DoNotDependOn("System.Net");
```

```csharp title="FluentAssertions"
AllTypes.From(_assembly).ThatAreUnderNamespace(_namespace).SelectMany(GetSignatureTypes).Should()
    .NotContain(type => type.Namespace != null &&
                        (type.Namespace == "System.Net" || type.Namespace.StartsWith("System.Net.")));
```
