# Feature comparison with FluentAssertions

aweXpect.Reflection and FluentAssertions both verify reflection types, with different APIs and
feature sets. This page maps what each offers for assemblies, types, and members.

## Conceptual model

FluentAssertions extends each reflection object with a synchronous `subject.Should()` entry point and
reaches collections through selectors such as `assembly.Types()` or `type.Methods()`. aweXpect.Reflection
wraps the same objects in an asynchronous `await That(subject)` call and builds collections from
`In.*` sources (`In.AllLoadedAssemblies()`, `In.AssemblyContaining<T>()`, …) that are narrowed with
`WhichAre*`/`With*` filter chains. aweXpect.Reflection also offers symmetric singular (`Is*`/`Has*`) and
plural (`Are*`/`Have*`) expectations for every target, while FluentAssertions pairs single-subject assertions
with a smaller set of selector assertions.

The sections below detail each target with side-by-side examples.

## Assembly

- **FluentAssertions** (`AssemblyAssertions`): `Reference`/`NotReference`, `BeSignedWithPublicKey`/`BeUnsigned`, `DefineType`. No assertion for assembly name, version, or target framework; use the string API on `assembly.GetName()`.
- **aweXpect.Reflection**: `HasName`, `HasVersion`, `DependsOn`/`DoesNotDependOn`/`DependsOnlyOn`, `IsStrongNamed`, `Targets`, `Has<TAttribute>`; plural equivalents (`HaveName`, …) over collections.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
assembly.Should().Reference(typeof(string).Assembly);
assembly.Should().NotReference(unwantedAssembly);
assembly.Should().BeSignedWithPublicKey("0024000004800000...");
assembly.GetName().Name.Should().Be("MusicStore");          // name via string API
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
await That(assembly).HasName("MusicStore");
await That(assembly).DependsOn("System.Core");
await That(assembly).DoesNotDependOn("UnwantedDependency");
await That(assembly).IsStrongNamed();

await That(In.AllLoadedAssemblies()).HaveName("System").AsPrefix();
```

</TabItem>
</Tabs>

## Type

- **FluentAssertions** (`TypeAssertions`): `Be<T>`/`NotBe<T>`, `BeAssignableTo<T>`, `Implement<T>`/`NotImplement<T>`, `BeDerivedFrom<T>`, `BeAbstract`/`BeSealed`/`BeStatic`, `HaveAccessModifier(CSharpAccessModifier)`, `BeDecoratedWith<T>` (with attribute predicate and `OrInherit` variants), member presence (`HaveProperty`/`HaveMethod`/`HaveConstructor`/`HaveIndexer`/`HaveExplicit*`), and conversion operators. Type *kind* is available only as a selector filter (`ThatAreClasses()`), and namespace
  only on the selector (`BeInNamespace`); a single type's name/namespace use the string API.
- **aweXpect.Reflection**: type-kind assertions (`IsAClass`, `IsAnInterface`, `IsAnEnum`, `IsAStruct`, `IsARecord`, `IsARecordStruct`, `IsARefStruct`, `IsADelegate`, `IsAnAttribute`, `IsAnException`), `IsAbstract`/`IsSealed`/`IsStatic`/`IsReadOnly`/`IsNested`/`IsGeneric`/`IsInstantiable`/`IsImmutable`, access modifiers (`IsPublic`, …), `InheritsFrom<T>().Directly()`, `HasName`, `HasNamespace`/`IsWithinNamespace`, `Has<TAttribute>`, quantified member containment (`ContainsMethods()`, …), member nullability (`OnlyHasNullableMembers`/`OnlyHasNonNullableMembers`), type-level dependencies (`DependsOn`/`DoesNotDependOn`/`DependsOnlyOn`/`HasDependenciesOutside`, against namespaces or type selections), operator presence by
  kind (`HasOperator(Operator)`, `HasOperator<TOperand>(Operator)`) and conversion operators by signature (`HasImplicitConversionOperator<TSource, TTarget>`, `HasExplicitConversionOperator<TSource, TTarget>`).

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
typeof(Playlist).Should().BeAssignableTo<IPlaylist>();
typeof(Playlist).Should().BeDerivedFrom<PlaylistBase>();
typeof(PlaylistBase).Should().BeAbstract();
typeof(Playlist).Should().HaveAccessModifier(CSharpAccessModifier.Public);
typeof(Playlist).Should().BeDecoratedWith<GenreAttribute>(a => a.Name == "Rock");
typeof(Playlist).Namespace.Should().Be("MusicStore");       // namespace via string API

// type kind only as a selector filter:
AllTypes.From(assembly).ThatAreClasses().Should().BeInNamespace("MusicStore");
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
await That(typeof(Playlist)).IsAClass();
await That(typeof(IPlaylist)).IsAnInterface();
await That(typeof(Genre)).IsAnEnum();
await That(typeof(PlaylistBase)).IsAbstract();
await That(typeof(Playlist)).HasNamespace("MusicStore");
await That(typeof(Playlist)).Has<GenreAttribute>(a => a.Name == "Rock");
await That(typeof(TrackDuration)).HasOperator(Operator.Addition);
await That(typeof(TrackDuration)).HasImplicitConversionOperator<TrackDuration, TimeSpan>();

await That(In.AllLoadedAssemblies()
        .Types().WhichAreClasses().WhichArePublic())
    .HaveNamespace("MusicStore").AsPrefix();
```

</TabItem>
</Tabs>

## Method

- **FluentAssertions** (`MethodInfoAssertions`): `BeVirtual`/`NotBeVirtual`, `BeAsync`/`NotBeAsync`, `ReturnVoid`/`NotReturnVoid`, `Return<T>`/`NotReturn<T>`, `HaveAccessModifier(CSharpAccessModifier)`, `BeDecoratedWith<T>`. No assertions for `static`/`abstract`/`sealed`/`generic`/extension/operator/override, no parameter assertions, and no name assertion (use the string API on `method.Name`).
- **aweXpect.Reflection**: the above plus `IsStatic`/`IsAbstract`/`IsSealed`/`IsGeneric`/`IsAnExtensionMethod`/`IsAnOperator` (incl. a specific `Operator`, e.g. `IsAnOperator(Operator.Equality)`), `Overrides<T>`, `ReturnsExactly<T>`/`DoesNotReturnExactly<T>`, `HasName`, and a parameter family: `HasParameter<T>`/`DoesNotHaveParameter<T>`/`HasParameterCount`/`HasInParameter`/`HasOutParameter`/`HasRefParameter`/`HasOptionalParameter`/`HasParamsParameter` (with `AtIndex`/`AtIndexFromEnd`/default-value refinements).

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
MethodInfo method = typeof(Playlist).GetMethod("PlayAsync");
method.Should().BeVirtual();
method.Should().Return<Task>();
method.Should().HaveAccessModifier(CSharpAccessModifier.Public);
method.Should().BeDecoratedWith<ObsoleteAttribute>();
method.Name.Should().StartWith("Play");                     // name via string API
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
MethodInfo method = typeof(Playlist).GetMethod("PlayAsync");
await That(method).IsPublic();
await That(method).IsAsync();
await That(method).Returns<Task>();
await That(method).HasName("Play").AsPrefix();
await That(method).Has<ObsoleteAttribute>();

await That(In.AssemblyContaining<Playlist>()
        .Methods().WhichArePublic().With<TestAttribute>())
    .HaveName("Test").AsPrefix();
```

</TabItem>
</Tabs>

## Property

- **FluentAssertions** (`PropertyInfoAssertions`): `BeVirtual`/`NotBeVirtual`, `BeReadable`/`BeWritable` (each with an optional `CSharpAccessModifier`), `NotBeReadable`/`NotBeWritable`, `Return<T>`/`NotReturn<T>`, `BeDecoratedWith<T>`. No assertions for `static`/`abstract`/`sealed`/`required`/indexer/init-setter/override, and no name assertion.
- **aweXpect.Reflection**: `IsReadable`/`IsWritable`/`IsReadOnly`/`IsWriteOnly`/`IsReadWrite`, `HasAGetter`/`HasASetter`/`HasAnInitSetter`, `IsStatic`/`IsAbstract`/`IsSealed`/`IsVirtual`, `IsRequired`, `IsNullable`, `IsAnIndexer`, `IsAnExtensionProperty`, `Overrides<T>`, `IsOfType<T>`/`IsOfExactType<T>` (and `IsNotOfType<T>`/`IsNotOfExactType<T>`), `HasName`, `Has<TAttribute>`.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
PropertyInfo property = typeof(Playlist).GetProperty("Rating");
property.Should().BeReadable(CSharpAccessModifier.Public);
property.Should().BeWritable();
property.Should().Return<int>();
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
PropertyInfo property = typeof(Playlist).GetProperty("Rating");
await That(property).HasAGetter();
await That(property).IsWritable();
await That(property).IsOfType<int>();
await That(property).HasName("Rating");

await That(In.AssemblyContaining<Playlist>()
        .Properties().WhichArePublic())
    .HaveName("Id").AsSuffix();
```

</TabItem>
</Tabs>

## Constructor

- **FluentAssertions**: no dedicated constructor selector. A constructor is reached through `Type.HaveConstructor(parameterTypes)` / `HaveDefaultConstructor()`, after which `.Which` exposes the `ConstructorInfo` for `HaveAccessModifier` / `BeDecoratedWith`.
- **aweXpect.Reflection**: dedicated expectations on a single `ConstructorInfo` and on collections of constructors, and an `In.*…Constructors()` filter: `IsStatic`, the full parameter family (`HasParameter<T>`/`DoesNotHaveParameter<T>`, `HasParameterCount`, `HasInParameter`/`HasOutParameter`/`HasRefParameter`/`HasOptionalParameter`/`HasParamsParameter`), `Has<TAttribute>`.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
typeof(Playlist).Should().HaveConstructor(new[] { typeof(int) })
    .Which.Should().HaveAccessModifier(CSharpAccessModifier.Public);
typeof(Playlist).Should().HaveDefaultConstructor();
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
await That(In.Type<Playlist>().Constructors().WhichArePublic())
    .HaveParameterCount(1);
await That(typeof(Playlist)).HasADefaultConstructor();
```

</TabItem>
</Tabs>

## Field

- **FluentAssertions**: no `FieldInfo` assertions.
- **aweXpect.Reflection**: expectations on a single `FieldInfo` and on collections of fields, and an `In.*…Fields()` filter: `IsStatic`, `IsReadOnly`, `IsConstant`, `IsRequired`, `IsNullable`, `IsOfType<T>`/`IsOfExactType<T>` (and `IsNotOfType<T>`/`IsNotOfExactType<T>`), access modifiers (`IsPublic`, …), `HasName`, `Has<TAttribute>`.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
// No dedicated FieldInfo assertions; fall back to raw reflection + LINQ/string assertions:
typeof(Playlist).GetField("_tracks", BindingFlags.Instance | BindingFlags.NonPublic)
    .IsInitOnly.Should().BeTrue();
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
FieldInfo field = typeof(Playlist).GetField("_tracks",
    BindingFlags.Instance | BindingFlags.NonPublic);
await That(field).IsReadOnly();
await That(field).IsPrivate();

await That(In.AssemblyContaining<Playlist>().Fields().WhichAreConstant())
    .ArePublic();
```

</TabItem>
</Tabs>

## Event

- **FluentAssertions**: no `EventInfo` assertions.
- **aweXpect.Reflection**: expectations on a single `EventInfo` and on collections of events, and an `In.*…Events()` filter: `IsStatic`, `IsAbstract`, `IsSealed`, `IsOfType<T>`/`IsOfExactType<T>` (and `IsNotOfType<T>`/`IsNotOfExactType<T>`), access modifiers, `HasName`, `Has<TAttribute>`.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
// No dedicated EventInfo assertions; fall back to raw reflection:
typeof(Playlist).GetEvent("Changed").Should().NotBeNull();
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
EventInfo @event = typeof(Playlist).GetEvent("Changed");
await That(@event).IsStatic();
await That(@event).Has<ObsoleteAttribute>();

await That(In.AssemblyContaining<Playlist>().Events().WhichArePublic())
    .HaveName("Changed");
```

</TabItem>
</Tabs>

## Selecting and filtering sets

- **FluentAssertions**: build a set with `assembly.Types()`, `AllTypes.From(assembly)`, `type.Methods()`, `type.Properties()`, then narrow with selector methods (`ThatAreClasses()`, `ThatDeriveFrom<T>()`, `ThatAreDecoratedWith<T>()`, `ThatAreInNamespace()`, `ThatReturn<T>()`, `ThatArePublicOrInternal`, `ThatSatisfy(predicate)`, …) and assert with the selector assertions. There are no `FieldInfo`/`EventInfo` selectors and no `ConstructorInfo` selector.
- **aweXpect.Reflection**: start from an `In.*` source, then chain `WhichAre*`/`With<T>`/`WithName`/`Without*` filters (with `Or*` combinations and quantifiers) across every member kind, and verify them with the plural `Are*`/`Have*` expectations.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
AllTypes.From(assembly)
    .ThatAreClasses()
    .ThatAreDecoratedWith<TestFixtureAttribute>()
    .Should().BeInNamespace("MusicStore.Tests");
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
await That(In.AllLoadedAssemblies()
        .Methods().With<FactAttribute>().OrWith<TheoryAttribute>()
        .DeclaringTypes())
    .HaveName("Tests").AsSuffix();
```

</TabItem>
</Tabs>

## Name and string matching

- **FluentAssertions**: reflection assertions have no built-in name matching. Names are compared with the string API (`type.Name.Should().StartWith(…)`) or a LINQ predicate on a selector.
- **aweXpect.Reflection**: every name/namespace/dependency comparison exposes string options: `AsPrefix()`, `AsSuffix()`, `AsRegex()`, `AsWildcard()`, `IgnoringCase()`, `Using(comparer)`.

<Tabs groupId="assertion-library">
<TabItem value="fluentassertions" label="FluentAssertions" default>

```csharp
type.Name.Should().EndWith("Tests");
```

</TabItem>
<TabItem value="awexpect" label="aweXpect.Reflection">

```csharp
await That(type).HasName("Tests").AsSuffix();
```

</TabItem>
</Tabs>
